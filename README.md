# MoneyClock

> 一个可以显示每一秒赚了多少钱的桌面时钟。

## 项目介绍

MoneyClock 是一个桌面时钟项目：在展示时间的同时，直观呈现“每一秒赚了多少钱”，让时间的流逝与收益的增长同步可见。

项目目前处于初始化阶段。仓库仅包含本说明文档与开源许可证，尚未提交源代码、依赖清单和构建配置。因此，下文的功能描述严格依据仓库已有的项目定位，技术栈与运行方式暂时无法确认，待代码提交后再行补充。

## 核心功能

根据当前的项目定位，MoneyClock 主要包含：

- **时钟展示**：以桌面时钟的形式显示当前时间。
- **每秒收益显示**：按秒展示收益金额，直观体现“时间就是金钱”。
